Query Coverage bezeichnet, wie vollständig eine Domain die Suchanfragen abdeckt, die ein KI-System zu einem Thema tatsächlich stellt. Ein Nutzer stellt eine Frage; das System zerlegt sie in mehrere Suchanfragen ([Query Fan-out](/wissen/geo-glossar/query-fan-out/)). Query Coverage fragt: Für wie viele davon steht Ihre Domain in den Top-Ergebnissen — nicht nur für die Hauptfrage, sondern für die verwandten Suchabsichten?

## Wie funktioniert Query Coverage?

Aus „Welcher Anbieter für Industriepumpen eignet sich für Abwasser?" werden intern Anfragen wie „Industriepumpen Abwasser Hersteller", „Abwasserpumpe Industrie Vergleich", „Abwasserpumpe Wartungskosten" und „Abwasserpumpe Feststoffe Fördermenge". Jede dieser Anfragen liefert eigene Kandidatenseiten. Eine Domain, die für drei davon rankt, ist dreimal im Kandidaten-Pool; eine Domain, die nur für die Hauptfrage rankt, einmal. Die Abdeckung entscheidet mit darüber, wie oft Passagen einer Domain ins [Re-Ranking](/wissen/geo-glossar/re-ranking/) gelangen.

## Warum ist Query Coverage für die KI-Sichtbarkeit wichtig?

Weil das Ziel nicht mehr das Keyword ist, sondern das Themenfeld. Eine Seite, die perfekt auf einen Begriff optimiert ist, deckt einen Bruchteil der Suchen ab, die ein KI-System ausführt. Query Coverage ist die messbare Seite von [Topical Authority](/wissen/geo-glossar/topical-authority/): Wer das Feld abdeckt, wird in mehr Teilergebnissen gefunden, liefert zu mehr Teilfragen passende Chunks und wird häufiger berücksichtigt.

## Was bedeutet das für Ihre Website?

Erstellen Sie je Kernthema eine Liste der Fragen, die Kunden vor, während und nach der Entscheidung stellen, und prüfen Sie, für welche davon Ihre Domain sichtbar ist — in Google und in Bing. Schließen Sie die Lücken mit eigenen Seiten oder klar geschnittenen Abschnitten, jeweils mit der Frage als Überschrift und der Antwort zuerst. Dieselbe Fragenliste ist die Grundlage für Ihr [Promptset](/wissen/geo-glossar/promptset/), mit dem Sie die KI-Sichtbarkeit anschließend messen.
